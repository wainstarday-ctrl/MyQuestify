# Зависимости сборки для Linux. Ставятся поверх requirements.txt.
#
# Почему отдельным файлом, а не маркером внутри общего списка: пакеты Qt
# весят сотни мегабайт и нужны только машине сборки под Linux. В общем
# списке они тянулись бы на Windows и macOS, где окно рисуют WebView2 и
# WebKit.
#
#   pip install -r requirements.txt -r requirements-linux.txt

# --- Оболочка окна ---------------------------------------------------------
# PyWebView на Linux умеет рисовать окно двумя способами: через GTK с
# WebKit2GTK и через Qt с QtWebEngine.
#
# Выбран второй. GTK брал бы движок просмотра из системы, а он есть не
# везде и называется по-разному: webkit2gtk-4.0 в одних дистрибутивах,
# 4.1 в других, а в третьих его нет вовсе — приложение открывало бы пустое
# окно, ничего не сообщая. QtWebEngine несёт движок внутри себя, поэтому
# собранный файл не зависит от того, что установлено у пользователя.
#
# Из двух привязок Qt к Python взята PySide6, а не PyQt5 или PyQt6.
# Причина правовая: PyQt распространяется под GPL-3.0, и приложение,
# несущее его в поставке, обязано распространяться на тех же условиях —
# что несовместимо с лицензией MIT этого проекта. PySide6 выпускается
# самой Qt Company под LGPL-3.0: она допускает использование в проекте с
# иной лицензией при условии, что пользователь может заменить саму
# библиотеку. Сборка каталогом это условие выполняет — библиотеки лежат
# отдельными файлами, а не внутри исполняемого.
#
# Цена решения — около 270 МБ в готовом архиве против 42 МБ у сборки для
# Windows, где движок берётся из системы.
qtpy>=2.4
PySide6>=6.6
