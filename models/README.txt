Каталог для весов локальной языковой модели.

Ожидаемое имя файла: model.gguf

ГДЕ ИСКАТЬ КАТАЛОГ
------------------
Запуск из исходников (python run.py):
    <корень проекта>\models\model.gguf

Собранный .exe:
    %LOCALAPPDATA%\MyQuestify\models\model.gguf

Внутри .exe этого каталога нет: временная папка распаковки доступна только
на чтение и стирается при выходе. Каталог в профиле пользователя создаётся
при первом запуске приложения.

ЧТО СКАЧАТЬ
-----------
Любая инструктивная модель в формате GGUF, квантованная под CPU:
подойдёт вариант Q4_K_M на 1-3 млрд параметров. Промпт собран в формате
ChatML (app/ai_module.py, функция _build_prompt) — для модели с другим
шаблоном достаточно изменить только эту функцию.

БЕЗ МОДЕЛИ
----------
Приложение запускается и работает: вместо генерации используется
детерминированный набор фраз. Статус виден в шапке интерфейса.
