# Метаданные каталога приложений

Отсюда клиент F-Droid берёт описание, значок и снимки экрана. Раскладка —
принятая в fastlane; её же читают и собственный репозиторий на страницах
GitLab, и IzzyOnDroid, поэтому один набор файлов годится для обоих каналов.

```
<язык>/
  title.txt               название, до 50 знаков
  short_description.txt   одна строка, до 80 знаков
  full_description.txt    описание, до 4000 знаков, обычный текст
  changelogs/<код>.txt    что нового, до 500 знаков
  images/
    icon.png              512×512
    featureGraphic.png    1024×500
    phoneScreenshots/     1.png, 2.png, …
```

**Имя файла с изменениями — числовой код версии, а не её номер.** Код
собирается сборкой из частей номера с запасом по сто значений на разряд:
3.0.1 даёт `30001`, 3.1.0 даст `30100`. Файл с чужим именем клиент просто
не покажет, не сообщив об этом.

Правило при выпуске: добавить `changelogs/<новый код>.txt` на обоих языках.
Старые файлы не удаляются — по ним видна история в карточке приложения.

## Снимки экрана

Лежащие здесь сняты на настольной версии: интерфейс тот же, но раскладка на
телефоне одноколоночная, и снимки с устройства выглядели бы честнее. Заменить
их можно прямо на месте, не трогая остальное — имена файлов задают порядок
показа.

Что снять с телефона: главный экран со списком квестов, открытую сцену,
цепочку мыслей в виде паутины, календарь сроков.

Движущиеся изображения из `docs/screenshots` сюда не годятся: каталог
показывает только неподвижные PNG и JPEG.
