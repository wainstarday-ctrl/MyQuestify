# Скриншоты для README

Файлы из этого каталога подставляются в README и открываются на странице
репозитория. Имена заданы жёстко: README ссылается на них напрямую, и
переименование разрываёт ссылки.

## Что снято?

| Имя файла | Что должно быть в кадре |
|---|---|
| `main-dark.png` | Главный экран, тёмная тема. Слева три-четыре квеста разного приоритета, хотя бы один завершённый и один с меткой срока. Справа открыта сцена. |
| `main-light.png` | Тот же экран в светлой теме. Снимать после переключения в настройках. |
| `lab.png` | Лаборатория Идей в момент реакции: подпись «Пена!» или «Дым!» ещё на экране, видна струя между колбами. |
| `scenes.png` | Магазин сцен целиком, с открытыми и запертыми позициями. |
| `thoughts-web.png` | Паутина рассуждений с деревом хотя бы на два уровня вложенности и выбранным узлом. |
| `oracle.png` | Чат с Оракулом: два-три обмена репликами и видимая правовая оговорка внизу. |
| `splash.png` | Экран загрузки с цитатой. Снимать в первые три секунды после запуска. |
