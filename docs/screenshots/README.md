# Скриншоты для README

Файлы из этого каталога подставляются в README и открываются на странице
репозитория. Имена заданы жёстко: README ссылается на них напрямую, и
переименование разорвёт ссылки.

## Что снять

| Имя файла | Что должно быть в кадре |
|---|---|
| `main-dark.png` | Главный экран, тёмная тема. Слева три-четыре квеста разного приоритета, хотя бы один завершённый и один с меткой срока. Справа открыта сцена. |
| `main-light.png` | Тот же экран в светлой теме. Снимать после переключения в настройках. |
| `lab.png` | Лаборатория Идей в момент реакции: подпись «Пена!» или «Дым!» ещё на экране, видна струя между колбами. |
| `scenes.png` | Магазин сцен целиком, с открытыми и запертыми позициями. |
| `thoughts-web.png` | Паутина рассуждений с деревом хотя бы на два уровня вложенности и выбранным узлом. |
| `oracle.png` | Чат с Оракулом: два-три обмена репликами и видимая правовая оговорка внизу. |
| `splash.png` | Экран загрузки с цитатой. Снимать в первые три секунды после запуска. |

Первые два обязательны — они попадают в шапку README и определяют первое
впечатление. Остальные дополняют разделы.

## Как снимать

**Инструмент.** Клавиша `Print Screen` захватывает весь экран вместе с
рабочим столом. Лучше `Win + Shift + S` — прямоугольная область, или
приложение «Ножницы» с задержкой, если нужно поймать исчезающий момент
(подпись реакции, экран загрузки).

**Размер окна.** Приведите окно к пропорции около 16:10 и ширине не меньше
1280 пикселей: на странице репозитория картинка сжимается по ширине колонки,
и мелкий текст становится нечитаемым.

**Наполнение.** Пустой интерфейс производит впечатление незаконченной
работы. Заведите пять-шесть квестов с осмысленными названиями, часть
завершите, чтобы на счётчике был ненулевой баланс, а в календаре — отметки.
Названия вроде «asdf» или «тест» лучше заменить: их видно на скриншоте, и
они говорят о проекте больше, чем хотелось бы.

**Момент для сцены.** Снимайте сцену в движении: падающие плоды, поток
лавы, разлетающиеся искры. Статичный кадр не передаёт, что сцена
интерактивна.

## Обработка

Ничего не требуется, кроме проверки размера. Если файл превышает 1 МБ,
пересохраните с меньшим разрешением: репозиторий с тяжёлыми изображениями
дольше клонируется, а разница в качестве на странице незаметна.

Формат — PNG. JPEG на скриншотах интерфейса даёт заметные искажения вокруг
текста.
